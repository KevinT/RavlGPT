### 2. ✅ Slash Commands Created

Three new commands are now available:

**`/copyright-check`** - Check header status
```bash
# Check all files
/copyright-check

# Check specific priority
/copyright-check --priority priority_1
```

**`/copyright-add [file|priority|all]`** - Add missing headers
```bash
# Add to specific file
/copyright-add common/new_file.py

# Add to Priority 5 files
/copyright-add --priority priority_5

# Add to all missing files
/copyright-add --priority priority_1 priority_2 priority_3 priority_4 priority_5
```

**`/copyright-verify [file|priority]`** - Verify header format
```bash
# Verify all
/copyright-verify

# Verify specific file
/copyright-verify common/ravl_base.py
```

### 4. ✅ Configuration File

**`.copyright-config.json`**

Defines:
- Header template
- File priorities (1-5)
- Exclusion patterns
- Settings

Edit this file to:
- Add new files to track
- Update copyright holder
- Modify header template

### 5. ✅ Optional Pre-Commit Hook

**`.claude/settings.json`**

Currently disabled (commented out). To enable automatic checking before git commits:

1. Edit `.claude/settings.json`
2. Remove the `_disabled` suffix from `_PreToolUse_disabled`
3. Save the file

The hook will warn you if files are missing headers before commits.

## Troubleshooting

**Command not found:**
- Make sure you're in the project root directory
- Verify `.claude/commands/` directory exists
- Restart Claude Code if commands don't appear

**Headers not detected:**
- Make sure the header is at the top of the file (after shebang)
- Check that it matches the template in `.copyright-config.json`
- Run `/copyright-verify [file]` to see specific issues

**Script errors:**
- Ensure Python 3 is installed
- Check that `.claude/scripts/copyright_manager.py` is executable
- Verify `.copyright-config.json` exists
