# RAVL Templates

Empty starting point templates for cloning new loops.

## Available Templates

### `empty_loop`
Minimal RAVL loop template with basic structure. Perfect starting point for any new loop.

### `strategic_coherence`
Template for strategic decision-making and coherence checking loops. Includes pattern-based analysis structure.

## Usage

Templates are designed to be cloned, not run directly:

```bash
# Clone empty loop for custom development
ravl --clone ravl.templates.empty_loop my_new_loop

# Clone strategic coherence template
ravl --clone ravl.templates.strategic_coherence my_strategy_checker
```

## Purpose

Templates provide scaffolding for common loop patterns. They are intentionally minimal to allow flexibility in implementation while ensuring core RAVL protocol compliance.
