# RAVL Examples

Working demonstration loops that showcase RAVL capabilities.

## Available Examples

### Basic Patterns
- `example_1_single_loop` - Simplest possible RAVL loop
- `example_2_nested_loops` - Parent-child loop coordination
- `example_3_analysis_loop` - LLM-powered content analysis
- `example_4_learning_loop` - Model persistence and learning patterns
- `example_5_python_loop` - Python class-based loop implementation

### Real-World Scenarios
- `example_communication_learner` - Communication pattern analysis
- `example_github_trending_tracker` - GitHub trending repository tracking
- `example_tech_news_curator` - News aggregation and curation
- `example_tech_news_dashboard` - Multi-source dashboard generation

## Usage

Examples run out of the box and can be cloned for modification:

```bash
# Run examples directly
ravl ravl.examples.example_1_single_loop
ravl ravl.examples.example_github_trending_tracker

# Clone for customization
ravl --clone ravl.examples.example_3_analysis_loop my_analyzer
```

## Purpose

Examples serve as learning resources and reference implementations. They demonstrate RAVL patterns, best practices, and integration techniques in working code.

**Note:** When cloning examples, the `example_N_` prefix is automatically stripped from the cloned loop name.
